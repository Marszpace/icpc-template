	Contribution technique: sum what each element adds
	Fix one end, sweep the other: or fix the max / middle
	Reverse the process: deletions -> insertions, time backwards
	Invariants, monovariants: sum, parity, xor, mod k, sorted
	Differences / prefix sums: neighbour ops become simple there
	Manhattan <-> Chebyshev: (x + y, x - y) turns L1 into L-inf
	Bound the answer: often <= 2, <= log n or <= sqrt n: try each
	Binary search the answer: when checking a value is easy
	Complement counting: count the bad ones and subtract
	Swap state and value: dp[value] = min cost, values small
	Coloring argument: checkerboard or mod k colours, parity
	Pigeonhole: n + 1 prefix sums mod n: a block divisible by n
	Sqrt threshold: heavy (> sqrt) vs light items, two methods
	Few distinct sizes: sum of sizes = n: O(sqrt n) distinct
	Layered / state graph: node = (vertex, extra state), then BFS

	Bit by bit from the top: greedy on xor / and / or optimum
	Lexicographic minimum: fix positions in order, check feasible
	Balanced ternary: digits -1, 0, 1: balance-scale weights
Counting
	Linearity of expectation: sum of P(indicator), even dependent
	E[X] = sum P(X >= k): for X >= 0 integer, e.g. E[max]
	Reflection principle: bad paths = paths to the mirrored end
	Inclusion-exclusion: sum over subsets of violated rules
	Kummer: v_p(C(n, k)) = carries of k + (n-k) in base p
	Vandermonde: sum C(a, i) C(b, k-i) = C(a+b, k)
	Stars and bars: C(n + k - 1, k - 1) ways to split n into k
	Hall: match all of L iff |N(S)| >= |S| for all S
	Erdos-Szekeres: n^2 + 1 terms: monotone run of n + 1
	Coupon collector: n H_n expected draws
	Graph enumeration: connected labeled graphs: log of the EGF
	Entringer / zigzag: alternating permutations, boustrophedon
	Young tableaux: hook length formula; RSK and LIS
	Probability bounds: Markov, Chebyshev, Chernoff, union bound
Greedy
	Exchange argument: sort by the pairwise comparison a < b
	Regret greedy: heap of choices you can still undo
	Deadline scheduling: by deadline, heap; drop worst if late
	Huffman merging: merge the two smallest, cost = merges
	Matroid: greedy is optimal; two of them: intersection
Dynamic programming
	Aliens trick (WQS): exactly k, convex in k: penalty lambda
	Knuth optimization: opt[i][j-1] <= opt[i][j] <= opt[i+1][j]
	Monotone queue DP: min over a sliding window of k
	Digit DP: count x <= N: (pos, tight, state)
	Broken profile DP: tilings of n x m, n small: bitmask row
	Rerooting: down pass, then up pass with prefix/suffix
	Tree knapsack: merging by subtree sizes is O(n^2) total
	DP over an automaton: state = (position, KMP / AC node)
	Dynamic DP: segment tree of (max,+) matrices, updates
	Steiner tree: dp[mask][v]: merge submasks, then Dijkstra
	Bounded knapsack: binary splitting, or monotone queue
	Bitonic tour: dp[i][j]: two paths ending at i and j
	Exchange DP order: iterate over the smallest dimension
	Expected value DP: backwards from the end; cycles: equations
	Garsia-Wachs: optimal alphabetic tree (merge cost)
Graphs
	Difference constraints: x_j - x_i <= w: edge i -> j, Bellman
	Residue Dijkstra: reachable sums: dist[r mod a_min]
	Min-plus matrix power: shortest walk with exactly k edges
	Kruskal reconstruction tree: path max edge, components <= w
	MST cycle property: heaviest cycle edge is never needed
	Boruvka: MST of an implicit graph (xor, geometry)
	Complement BFS: keep a set of unvisited, scan it
	Triangles in O(m sqrt m): orient edges low -> high degree
	Planar bounds: E <= 3V - 6; V - E + F = 2
	Grid is bipartite: (i + j) parity: matching / flow / cover
	Expected hitting times: linear system; on a tree, DP
	Tree isomorphism: canonical form or hash of sorted children
	Dominator tree: vertices every s -> v path passes
	Stable matching: Gale-Shapley proposals, O(n^2)
	0-1 BFS: deque: weight 0 front, weight 1 back
	Min mean cycle: Karp O(VE), or binary search + Bellman
	Shortest cycle: BFS from each vertex, O(VE)
	K-th shortest path: Eppstein; or A* with exact heuristic
	Euler tour flattening: subtree = a range of dfs times
	Long-path decomposition: depth DP in O(n) total
	Edge coloring: bipartite: max degree colours; else <= D + 1
	Vertex coloring: k colours: 2^n incl.-excl. over indep. sets
	Chordal graphs: perfect elimination order (max card. search)
	Max-weight general matching: weighted blossom, O(n^3)
	Min diameter spanning tree: absolute centre of the graph
	Dynamic graphs: extra book-keeping per change
	Lovasz toggle
Data structures
	Queue from two stacks: sliding min / gcd without undo
	Cartesian tree: recursion on the minimum; O(n) with stack
	Nearest smaller values: monotone stack; histogram rectangles
	Segment tree merging: merge dynamic trees small to large
	Rebuild every sqrt(Q): buffer updates, recompute periodically
	Binary trie: max xor pair, count xor <= k
	Zobrist / xor hashing: random 64-bit per item: set equality
	Merge sort tree / wavelet: k-th or count in a range, static
	Small to large: each item moves O(log n) times
Advanced data structures
	Splay tree: amortized log; accessed node goes to the root

	Persistent block array: sqrt blocks, copy on write
	Finger tree: O(1) at both ends, log split / concat
	Disjoint sparse table: (cat tree) O(1) query, any assoc. op
	Sqrt tree: O(1) range query, O(n log log n) build
	Kinetic segment tree: max of a_i + t b_i as t only increases
	Euler tour tree: dynamic forest with subtree aggregates
	Top tree: dynamic trees, path and subtree ops
	Global balanced binary tree: HLD paths as weighted BSTs
	Block list: list of sqrt-size blocks, split / merge
	Tree blocking: cut a tree into O(sqrt n) clusters
	Tree in tree: segtree of treaps / BIT of value segtrees
	PQ tree: orders with consecutive-ones constraints
	Quadtree: 2D subdivision (usually kd-tree is better)

Number theory
	Frobenius number: ab - a - b largest non-sum, gcd = 1
	Stern-Brocot: best rational approximation, binary search
	gcd of powers: gcd(a^m-1, a^n-1) = a^gcd(m,n)-1; same for F

	Sum of two squares: p = 1 mod 4 primes; Gaussian integers
	Vieta jumping: (x, y) -> (k y - x, y), descent
	Hensel lifting: root mod p -> mod p^k
	Pell equation: x^2 - d y^2 = 1 from continued fractions
	Min_25 sieve: prefix sums of multiplicative f
	Powerful number sieve: f = g * h, h only on powerful numbers
	Zhou's sieve: multiplicative prefix sums (like Min_25)
	k-th roots mod p: via primitive root + discrete log
	Quadratic fields: arithmetic in Z[sqrt d] (closed forms)
	Quadratic reciprocity: Legendre symbols of odd primes p, q
